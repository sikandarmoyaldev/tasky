## About this template

**Smart minimal to-do list app.** Create, organize & track tasks. Built with **Next.js + Shadcn UI**. Dark mode, search, categories, priority levels.

## Features

• **Light/Dark Mode** - Toggle themes for personalized experience  
• **Fully Responsive** - Perfect on mobile, tablet, desktop  
• **Accessible Design** - WCAG compliant, screen reader ready  
• **Task Management UI** - Clean interface for creating/editing tasks  
• **Custom Shadcn Components** - Reusable, extendable UI elements  

## Tech Stack

- [Next.js](https://nextjs.org/)
- [Shadcn UI](https://ui.shadcn.com/)  
- [Lucide React](https://lucide.dev/)  
- [TypeScript](https://www.typescriptlang.org/)  
- [Eslint](https://eslint.org/)
- [Prettier](https://prettier.io/)
